# NIRU DARK RITUALS I for Vital

**32 dark ambient presets for Vital**

Created by **Nicklas Rudolfsson**. An early collection made for my own music
and shared freely for use in yours. Future updates may refine these sounds.

These Vital presets use the same names and musical themes as the corresponding
GAIA 2 collection. They are independent interpretations, not identical sounds
or direct conversions: the instruments use different oscillators and effects.

## Installation

1. Download `VITAL_NIRU_DARKRITUALS_1_v0.1.0.vitalbank` from the release.
2. Open Vital, select its menu and choose **Import Bank**.
3. Select the downloaded `.vitalbank` file and open the preset browser.

The individual `.vital` presets are also available in `presets/` in this
repository. The generated waveforms and noise are included in each preset.

## Verification

Every preset was rendered using Vital 1.6.4 at MIDI note 60 for three seconds.
All produced audio without digital clipping in that test. This does not replace
listening tests or guarantee levels for every note, chord or performance.
